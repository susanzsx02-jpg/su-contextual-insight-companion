# Su’s Contextual Insight Companion｜Su 的情境洞察伙伴

一个从真实经历与具体问题出发，通过连续对话、跨学科分析和现实验证来理解现象背后机制的 AI Skill。

> 当前版本：v0.3（沿用既有 v0.3 的运行规则，仅更新公开名称及 Skill 标识）。

## 为什么做这个 Skill？

日常生活中，我们经常观察到某种现象或遇到一个卡点，却不知道如何进一步追问和分析。这个 Skill 希望帮助使用者从真实情境出发，识别重要问题，寻找可能的解释，并把相关知识放回现实中理解和验证。

## 核心特长

- **情境理解（Contextual）**：先理解具体经历、当前需求、现实条件和已知事实，不套通用答案。
- **深度洞察（Insight）**：通过关键追问、问题建模及按需跨学科分析，区分现象、解释与待验证假设。
- **持续陪伴（Companion）**：对话、学习、实践、反馈、复盘连续进行，逐步形成可迁移的知识。
- **证据约束**：重要概念尽可能核对原始含义、学科归属、证据水平和适用边界，不把猜测当成事实。

核心闭环：真实经历 → 识别问题 → 分析机制 → 理论映射 → 现实验证 → 反馈复盘 → 认知积累。

## 适用场景

可用于赚钱实践、工作、学习、个人成长、人际关系、生活观察等真实问题的探索。具体分析维度由问题决定；单一维度足够时，不强制扩展。

## 如何使用

1. 下载或复制本仓库的 [`SKILL.md`](SKILL.md)。
2. 将文件提供给能够读取 Markdown 文件的 AI，告诉它：**“请完整读取这份 SKILL.md，并在后续对话中遵循其中适用的规则。先理解我的情境，必要时逐步追问，不要机械套用所有分析维度。”**
3. 用自然语言讲述你遇到的问题、真实经历或观察到的现象；根据对话继续补充信息。
4. 需要时让 AI 引入可靠知识和案例，并结合实际反馈复盘。
